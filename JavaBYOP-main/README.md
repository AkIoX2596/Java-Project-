## Problem

Students spend money daily but do not track where it goes. At the end of the month, it becomes difficult to understand how the budget was exceeded. This project solves that problem using a Java console application to record, categorize, and analyze expenses.

## Features

- Add daily expenses with category and note
- View all expenses
- Category-wise spending summary
- Monthly budget setting and warning
- Data saved to file and loaded automatically

## Technologies Used

- Java
- OOP concepts
- ArrayList, HashMap
- File handling (serialization)
